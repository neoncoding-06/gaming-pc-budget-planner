    How it works

    1. Enter a budget. JavaScript checks that it is a valid number in range.
    2. Pick a tier. A script picks the best compatible part of every type that fits your budget, then spends any leftover money on upgrades.
    3. Add it up. The script totals the part prices and subtracts them from your budget.
    4. Show results. Cards, FPS bars and the store table are created with safe DOM methods.

    NeonRig is an educational college project. All prices and FPS figures are demo estimates, not live data and not guaranteed. Store links open real search pages, where actual prices may differ.
